1C AI Integration
AI-ассистент, встроенный напрямую в платформу 1С:Предприятие 8. Позволяет общаться с языковыми моделями не выходя из 1С, передавать в контекст данные из базы, выполнять сгенерированный код и строить диаграммы.

Возможности

💬 Чат с AI прямо внутри 1С — история диалогов сохраняется в базе
🤖 Поддержка любых OpenAI-совместимых API — YandexGPT, GigaChat, OpenRouter, DeepSeek, GPT и другие
🗂️ Передача объектов 1С в контекст — справочники и документы сериализуются в JSON и отправляются модели
▶️ Запуск кода прямо из чата — сгенерированный 1С-код можно выполнить кнопкой Run
🔧 Автоисправление ошибок — при ошибке выполнения кнопка «Исправить» отправляет текст ошибки обратно модели
📊 Визуализация — поддержка Mermaid-диаграмм и Chart.js графиков в ответах
🌗 Светлая и тёмная тема интерфейса
📁 Прикрепление файлов — изображения и документы передаются в контекст
🏷️ Автоназвание чатов — тема диалога определяется моделью автоматически
👥 Мультиагентность — несколько ассистентов с разными моделями и настройками


Технологии
| Слой | Стек |

| Платформа | 1С:Предприятие 8.3 |

Установка

Скачай файл .dt из релизов
В 1С откройте Конфигуратор → Администрирование → Загрузить информационную базу
Укажи скачанный .dt файл — база загрузится полностью готовой
Перейди в Настройки → Ассистенты AI и добавь агента:

Укажи название модели
Вставь API-ключ
Введи URL эндпоинта (например https://openrouter.ai/api/v1)

⚠️ GigaChat требует особого формата авторизации (OAuth + двухфакторный токен Сбера) — интеграция с ним не тестировалась.

Быстрый старт
После установки откройте форму AI Ассистент из меню или раздела. При первом запуске автоматически создаётся новый чат.
Загрузка данных из базы:

Нажмите кнопку 📎 «Прикрепить объект»
Выберите тип (Справочник / Документ) и конкретный элемент
Структура объекта будет передана в контекст

Запуск кода:

Попросите модель написать код на 1С
Наведите мышь на блок с кодом — появится кнопка ▶ Run
Результат выполнения отобразится в чате
